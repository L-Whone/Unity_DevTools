A1 Dev Tool ReadMe



Scripts:

\- CreateNewSceneSetup



Features:

This Dev tool creates a new scene with additive scenes pre-loaded as Grouping of Logic (Cameras, Lighting, Characters, etc).

It creates a new base scene, saves it, then creates new additive scene based on the input of the user. The tool also

spawns any game objects the user wants to have spawned in each additive scene.



The scenes are uploaded to the build settings automatically.



To Test:

Import CreateNewSceneSetup as a script in Assets/Editor folder

Open "Tools" dropdown and generate a new scene setup



Dependencies:

* Quin Henshaw - UnityTools https://github.com/qhenshaw/UnityTools.git
* Cinemachine
* Odin Inspector
